6. TECHNICAL ARCHITECTURE SUMMARY:
--------------------------------------------------------------------------------
- Backend Architecture:
  * Runtime: Java 21 LTS, Spring Boot 4.1.1
  * Security: Spring Security 6, Stateless JWT (JJWT 0.12.6, HMAC-SHA256)
  * Refresh Token Strategy: Secure UUID tokens stored in PostgreSQL with
    expiration tracking, single-use rotation, and revocation on logout
  * Database: PostgreSQL (Render Managed PostgreSQL instance: zephyra_auth_db)
  * Dialect & ORM: Spring Data JPA, Hibernate 7
  * Containerization: Multi-stage Dockerfile (eclipse-temurin:21) with dynamic $PORT
  * Tests: 20 automated tests (Unit & MockMvc Integration tests, 100% passing)

- Frontend Architecture:
  * Runtime: Next.js 16.4.0 (Turbopack), React 19, TypeScript
  * Styling: Tailwind CSS 4 with custom light corporate theme (Blue/Slate)
  * Session Management: AuthContext with localStorage persistence
  * Token Interceptor: Axios-like resilient fetch client that automatically detects
    HTTP 401, issues a POST /api/auth/refresh-token request, rotates tokens,
    and replays pending requests seamlessly
  * Profile & User Management: Standard users can edit their profile details directly
    in the dashboard; administrators can edit usernames, emails, account active/disabled
    status, and assigned roles in the admin portal.
