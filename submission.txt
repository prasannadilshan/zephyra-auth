Instructions for Creating a Test Account

New test accounts can be self-registered directly via the web interface:
1. Navigate to: https://zephyra-auth.vercel.app/register
2. Fill in username, email, and password (minimum 6 characters).
3. Submit the registration form and log in via https://zephyra-auth.vercel.app/login.
(Alternatively, register via API: POST https://zephyra-auth.onrender.com/api/auth/register)
All public registrations receive standard user (ROLE_USER) permissions safely.
